Step 1 / 3

Engineering decisions

The implementation, its guarantees and its boundaries.

Retrieval

Lexical first, measured next

Vespa indexes titles and document bodies. The title gets twice the BM25 weight. Vector and hybrid retrieval remain future experiments; no quality improvement is claimed without evaluation.

Serving

Bound the work

Search requests accept up to 256 characters and 10 results. A shared adapter allows eight concurrent searches per process, with a 2-second Vespa query timeout and a 5-second HTTP client timeout.

Evidence

Keep the source attached

Results include a stable document ID, source reference and corpus version. The original summaries are educational material; their links are further reading, not a claim that source pages were indexed.

Operational choices

AreaImplementedBoundary
IngestionStable IDs and replacement writes make the fixed corpus replay-safe.No bulk checkpoints or deletion reconciliation yet.
AvailabilityReadiness probes query Vespa; liveness checks the API process.One Vespa node; no replica failover or HA claim.
ResourcesA VM profile caps memory and reduces JVM heaps for this tiny corpus.Below Vespa’s usual memory recommendation; not a production sizing model.
ObservabilitySearch request, error and cumulative duration counters; private aggregate traffic dashboard.No latency histogram, distributed traces or unique-visitor count.
DeploymentGitHub Actions verifies the commit, connects with pinned SSH identity, then checks the public endpoint.No automatic rollback; persistent data volumes are preserved.
Data accessVisitors can search and read documents through HTTP or MCP.Ingestion stays internal. RDF/SPARQL and arbitrary database queries are not exposed.

Independent engineering POC. Aggregate page views and interactions are counted for 30 days, without cookies, IP storage or personal identifiers. Counts include the page and an optional campaign tag from a fixed list. No raw query text is stored in analytics. Counts may include bots or reloads and cannot identify a person.
